# Belajar Mengaji — Awal Sampai Bisa

Website edukasi statis profesional dan responsif.

## Fitur
- Landing page modern
- Dashboard progres belajar
- 6 kategori pembelajaran
- 29 huruf hijaiyah dengan Web Speech API
- Juz Amma / daftar surah
- Doa harian + audio browser
- Kuis interaktif
- Skor terbaik tersimpan di localStorage
- Progres tersimpan di browser
- Responsive untuk HP, tablet, desktop
- Tanpa database dan tanpa biaya hosting

## GitHub Pages
1. Buat repository baru di GitHub, misalnya `belajar-mengaji`.
2. Upload semua file ini.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. Buka `https://USERNAME.github.io/belajar-mengaji/`

## Catatan
Subdomain `USERNAME.github.io` dapat digunakan gratis melalui GitHub Pages. Domain khusus seperti `.com` biasanya memerlukan registrasi berbayar.
